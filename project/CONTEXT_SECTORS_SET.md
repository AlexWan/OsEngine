# CONTEXT_SECTORS_SET — Сборник «Сектора в алго» (секторальные трендовые роботы)

> Публичный контекст сборника для ИИ-агентов и разработчиков.
> Назначение: быстрый вход в устройство секторальных роботов `SectorsSetBollingerMomentum` и `SectorsSetAlligatorTurtle`.

---

## 1. Что это

Два трендовых робота для акций MOEX, торгующих по секторам экономики. Общая идея: деньги на рынке ротируются между секторами — роботы покупают сильнейшие бумаги внутри сильнейших секторов (по RSI-рейтингу) и выходят по трейлинг-стопу. Свободные деньги паркуются в фонде денежного рынка TMON отдельным ботом `TMONRebalancer` (`Robots/Helpers/TMONRebalancer.cs`), который запускается рядом и в тестере, и в реале.

Код роботов: `Robots/Sectors/SectorsSetBollingerMomentum.cs`, `Robots/Sectors/SectorsSetAlligatorTurtle.cs`.

## 3. Конструкция роботов

**Источники:** `BotTabScreener` ×9 — по одному на сектор. Списки бумаг пользователь может править в интерфейсе скринера.

**Монитор секторов (общий блок):**
- RSI на каждой бумаге (параметр `Monitor rsi length`).
- Показатель сектора = средний RSI его бумаг (только прогретые).
- Входы разрешены только в топ-N секторов (`Monitor trade sectors count`).
- Отбор бумаги внутри сектора: `Monitor entry filter` = None / Strongest / Weakest (по RSI бумаги в секторе).
- Таблица монитора — кастомная вкладка ` Monitor ` в окне параметров (Sector / Ticker / RSI / Sector RSI / Rank / In top / Chart), цвета секторов чередуются из активной темы.

**Точки входа в логику по режимам:**
- Реал: `CandleFinishedEvent` скринеров → одноразовый таймер 5 сек → `Logic()` на последних данных (без проверок синхронизации).
- Тестер: `TesterServer.EndNextMinuteWithCandlesEvent` → `Logic()`.
- Оптимизатор: первая свеча как триггер → подписка на `OptimizerServer.EndNextMinuteWithCandlesEvent`.
- Guard «новая свеча» по каждому табу: действия по закрытой свече раз на свечу (`TimeStart` в словаре).

**Торговые правила (оба робота):** только лонг; жёстко 1 позиция на сектор; общий лимит `Max positions`; вход — `BuyAtStopMarketIceberg` на пробой (жизнь заявки 1 свеча, перед перевыставлением `BuyAtStopCancel()`); выход — ручной трейлинг `CloseAtStopMarketIceberg` по линии индикатора, только в сторону прибыли, только в торговое время; неторговые периоды — `NonTradePeriods` (предустановка 10.00–18.00, выходные мимо), в неторговое время заявки на вход отменяются, стопы позиций спят (`StopOrderIsActive`); комиссия в тестере 0.04% при авто-деплое.

**Важно про параметры:** набор параметров в тестере и оптимизаторе обязан совпадать (оптимизатор сверяет `Parameters.Count` при одиночном прогоне) — поэтому параметры авто-деплоя тестера создаются и в оптимизаторе.

**Робот №1 `SectorsSetBollingerMomentum`:** Bollinger (40 / 2.1) — канал входа/выхода; Momentum (65, порог 101.1) — импульс; Envelop (170 / 1.6) — фильтр перегретости (цена ниже верхней линии — лонг запрещён); RSI (64) — монитор. Вход стопом по верхней полосе (условия: цена выше середины и ниже верха канала), выход трейлингом по нижней полосе (`Exit band` = Down, можно Middle).

**Робот №2 `SectorsSetAlligatorTurtle`:** Alligator (60 / 25 / 5) — цена выше всех линий + порядок Lips > Teeth > Jaw; PriceChannel длинный (14) — вход по пробою верхней границы (условия по `Values[Count-2]`, активация по последнему); PriceChannel короткий (20) — трейлинг по нижней границе; RSI (74) — монитор.

## 4. Стандартные настройки (после оптимизации, 09.09.2026)

Оба: Regime Off · **Volume 12.5% депо на сделку** · Max positions 4 · айсберги 3 × 1000 мс · entry filter Strongest. Робот №1: RSI 64, топ-5 секторов. Робот №2: RSI 74, топ-5 секторов.

> Расчёт плеча комплекта: 2 робота × 4 позиции × 12.5% = 100% депо максимум — **первое плечо, не выше**.
